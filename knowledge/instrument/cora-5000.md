# Cora 5000

- **Excitation:** 532 nm only in practice; the 1064 nm channel is dead ([decision](../decisions/2026-11-23-532-only.md)).
  2048-pixel detector, raw axis about −660 to 4190 cm⁻¹ (anti-Stokes included).
- **Laser power:** set by hand on the instrument, not from software. Features may advise ("lower the power")
  but cannot act.
- **Sample:** a single GC vial in a closed compartment, like a UV-vis cuvette holder. No stage, no mapping, no
  operando cells. Every spectrum goes through vial glass; powder heterogeneity is handled by shaking/rotating the
  vial between repeats (issue #11).
- **Edge filter:** cuts the signal below ~150 cm⁻¹. Baselines, peak picking and plots use 150 cm⁻¹ as the lower
  limit (`processing::kBaselineFitMin`, issue #5).
- **Factory file:** vendor `BS_Device_Settings.ini` per serial (Instrument → Load factory calibration…);
  wavelength polynomial, laser data, and `NIST_Coeff_00..05` = the SRM 2242 certificate curve
  (see [intensity response](../processing/intensity-response.md)).
- **Control PC:** the Raman PC ran Windows 10 1511 (vendor software); Linux has since been set up on it for
  LibreRamen. A legacy Windows 10 1511 / PySide2 build of the Python app is shelved on beryllium (branch
  win10-1511-legacy). Other lab instruments: [lab](../lab/index.md).
- **Laser safety:** lasers only on inside an acquisition, with ARM and closed compartment (PROTOCOL.md,
  `core/instrument.h`).
- Planned work for black battery materials (heating, weak signal): issues #9–#15.
